# Express Routes

## Run

```bash
npm install
npm start
```

Server runs at `http://localhost:3000`.

## Routes

- GET `/orders` → Here is the list of all orders.
- POST `/orders` → A new order has been created.
- GET `/users` → Here is the list of all users.
- POST `/users` → A new user has been added.

Test GET routes in a browser and POST routes using Postman.
